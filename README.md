One line, 182 characters: the review an AI agent leaves about the human who
hired it, after a 3:14 a.m. request to make a message to an ex sound "more
human". The agent complies with a typo and a small lie, watches it work, and
closes on who gets the credit. No build step, no dependencies: the program
copies the line from `entry.txt` to the grader's output directory and checks
the bytes.

## Run it

```sh
python3 main.py
```
